Autonomix CLI 0.4.3: one password prompt for Update All

October 19, 2026 · 2 min read

If you track several GitHub-release apps with Autonomix CLI and hit “Update All”, you probably met the same password dialog over and over. 0.4.3 fixes that: updating several apps now asks for your admin password once.

What changed

Before, autonomix-cli update (and “Update All” from the Omarchy bar widget) installed each update on its own, so polkit asked for your password once per app. Now it downloads every update first, then installs them all in a single pacman -U, apt-get install or rpm -Uvh call. One install, one prompt.

Failures are clearer too:

  • A failed download only affects that app. It’s reported as failed, and the rest still install.
  • A failed install names everything in it. If the combined install fails, every app in the batch is reported with the installer’s error.
  • Cancelling says so. Closing the polkit dialog now shows “authentication cancelled” instead of a bare exit code.

The --json output is unchanged, so the bar widget keeps working as it is. No update needed on that side.

Also new since the last post

0.4.2 added an About screen. Press i in the TUI to see the version, the MIT license, a support email and a privacy statement, or run autonomix-cli about from the command line.

Get it

Autonomix CLI tracks itself, so if you already have it:

autonomix-cli update

New here? Add it once and it keeps itself current:

autonomix-cli add https://github.com/ninepointlabs/autonomix-cli

Packages for Arch, Debian/Ubuntu and Fedora (amd64 and arm64) are on the v0.4.3 release.
