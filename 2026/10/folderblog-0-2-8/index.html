folderblog 0.2.8: Podcast setup that works on real R2, and a Subscribe box

October 24, 2026 · 2 min read

folderblog 0.2.8 is a small fix release on top of yesterday’s 0.2.7, the one that turned a blog folder into a podcast. If you tried folderblog podcast setup and it stopped at the “find it again” step, this is the release you want.

Podcast setup works with real Cloudflare R2

After setup uploads a small test file, it checks that the file can be found again. On real Cloudflare R2 that check failed even though the upload had worked. R2 compresses some files on the way out, and when it does, its reply leaves out the file size, so folderblog read the missing size as a missing file.

folderblog now asks R2 for uncompressed replies, so the size comes back. If a reply still has no size, any successful answer counts as “the file is there”, and the size is only compared when R2 sends one. The same fix applies when a deploy checks whether an episode’s audio is already uploaded, so a working upload isn’t treated as missing. The tests now use a fake R2 that compresses the way the real one does, which is how this slipped through before.

This is the fix that got the first real show on folderblog running. My Azeroth Life was set up with it, and the story of how that show is made is here on the blog.

Easier to subscribe

  • The podcast feed has its own title. When the show and the blog share a name, the podcast feed is now called “Your Blog (Podcast)”, so feed readers and browsers can tell it apart from the blog feed.
  • A Subscribe box on the show page. The podcast page that folderblog podcast on sets up now has a Subscribe section near the top, with the full feed address ready to select and paste into a podcast app. It’s plain CSS that uses your theme’s colors, with no JavaScript.

Grab it

SystemCommand
Arch / Omarchysudo pacman -U folderblog-bin-0.2.8-1-x86_64.pkg.tar.zst
Debian / Ubuntusudo apt install ./folderblog_0.2.8-1_amd64.deb
Fedora / RHEL / openSUSEsudo dnf install ./folderblog-0.2.8-1.x86_64.rpm
autonomix-cliautonomix-cli add https://github.com/ninepointlabs/folderblog

Already installed? Install the new package, then run systemctl --user restart folderblog. The packages and a plain tarball are on the v0.2.8 release, and the source is on GitHub.
