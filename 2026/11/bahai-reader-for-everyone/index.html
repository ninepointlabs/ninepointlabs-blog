Bahá’í Reader for everyone: rebuilt with Flutter

November 17, 2026 · 3 min read

Bahá’í Reader, the offline prayer book and Writings reader, started out as a GTK app for Linux. We’ve rebuilt it with Flutter, so the same reader now runs on Linux, Windows and Android. Version 1.0 is the first release of the new app.

Why Flutter

Let’s get one thing out of the way: we’re still Omarchy users. Most of what we make at Nine Point Labs is built for Linux and Omarchy first, and that isn’t changing.

Bahá’í Reader is a little different. A prayer book is something you reach for on whatever is in front of you: the family laptop, a phone at a devotional gathering, the computer at work. The people who could use it aren’t all running Linux, and an app full of prayers and the Writings should be shared with whoever needs it. Flutter lets us keep one codebase and ship it to many platforms, so a fix or a new feature reaches everyone at once.

Same reader, new home

Before switching, we listed every feature of the GTK app and worked through them one by one, so the move wouldn’t cost anyone the things they rely on. What you know is still here:

  • Offline, and private. English is bundled. Other languages download only when you ask, and nothing else ever uses the network. No accounts, no analytics, no telemetry.
  • The library and search. Writings grouped by book, prayers grouped by category, and a search that ignores accents and apostrophes, so “Bahaullah” finds “Bahá’u’lláh”.
  • Highlights, notes and saved passages, plus Copy with citation.
  • Today and the obligatory prayers. The Badí‘ date (changing at sunset), sun times for your city, your obligatory prayer’s window with a private “Said today”, the next Feast and Holy Day, the Fast, the passage of the day and the Alláh-u-Abhá counter.
  • Light, Dark and Sepia, and on Omarchy it still follows your live theme.

If you used the GTK app on Linux, the first start brings over your highlights, notes, saved passages, collections, reading places and settings. The old app’s files are only read, never changed, so nothing is lost if you go back.

Where it runs today

  • Linux, where we use it every day: the .deb, .rpm, Arch/Omarchy package, AppImage and Flatpak bundle are all there, or install it with autonomix-cli.
  • Windows (64-bit): an installer that doesn’t need administrator rights, or a zip. Last night I tested it on Windows myself, and it works well. It isn’t code-signed yet, so SmartScreen may warn you the first time; choose More info, then Run anyway. Reminders aren’t sent on Windows yet.
  • Android (7 and up, phones and tablets): an APK you install from the download page. The phone opens on a Today tab, and reminders arrive even with the app closed.

What’s left: macOS and iOS

The Flutter project already has the starting pieces for macOS and iOS, but neither has been built or tested. Building for Apple platforms needs a Mac, and we don’t have one yet. When we get one, macOS and iOS are next. Until then we’d rather say “not yet” than ship something we haven’t tried.

Get it

Downloads for every platform are on bahaireader.org and the GitHub releases page. On Linux, autonomix-cli keeps it up to date:

autonomix-cli add https://github.com/ninepointlabs/bahai-reader
autonomix-cli install bahai-reader
# or, if you already track it:
autonomix-cli update

The source is on GitHub. The code is MIT licensed; the texts and translations are not, and DATA-NOTICE.md has the details. This is a free, independent community app, not an official publication of a Bahá’í institution.

Thank you to everyone who has prayed, read and studied with Bahá’í Reader so far. It’s a joy to be able to share it with more people.
