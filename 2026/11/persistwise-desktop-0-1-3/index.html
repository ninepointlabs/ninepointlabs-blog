Persistwise Desktop 0.1.3: save whole forum threads and choose your archive folder

November 27, 2026 · 4 min read

Three days after the first release, Persistwise Desktop has three updates. They came out of a request from a Linux user archiving old forums and blogs. Version 0.1.1 adds whole-thread saving and lets you choose where your archive lives, 0.1.2 is a small fix for Omarchy light themes, and 0.1.3 makes thread saving work on old Invision Power Board forums. All are free and open source on GitHub.

Save a whole thread

Next to the Wayback checkbox there’s a new one: Save the whole thread. Tick it, paste the first page of a multi-page forum topic or a paginated blog archive, and Persistwise follows the “next page” links and saves every page, in order, as one item. Plain Save works the same as before.

  • It works with the usual forum and blog software (phpBB, vBulletin, XenForo, Discourse, Invision Power Board and WordPress-style pages), with nothing written for one site in particular.
  • It stays on the same site, stops if it loops back to a page it has already seen, and saves up to 100 pages, waiting a moment between them.
  • The library shows a thread as one item with its page count. In the reader you move through it with Previous, a page picker and Next, and a search hit inside a thread tells you which page it’s on.
  • If a page fails or the limit is reached, the pages saved so far are kept and the thread is marked partial, with the reason.

Save it again to catch up

Forum threads keep growing. Save an archived thread again, from any of its pages, and Persistwise reuses the pages it already has without fetching them again. It checks the last page for new replies and replaces that copy only if something changed, then adds any new pages after it. You get no duplicates, and Wayback and IPFS only see the new and updated pages.

When the last page’s copy is replaced, its old IPFS pin is removed from your own node or your Pinata account, unless another saved page has the same content. If you use Pinata, your key now needs permission to read and write files.

Choose your archive folder

Your archive no longer has to live in the default folder. Under Settings → Storage you can move it somewhere else, copy it, or start a fresh archive, keeping your settings and API keys or not. Pick a folder that already holds an archive and Persistwise opens it as it is.

If the folder is missing when the app starts (say, a USB drive that isn’t plugged in), you get a recovery screen with Retry, Choose a different folder and Use the default folder. Persistwise never quits silently and never creates an empty archive unless you ask it to.

Old Invision Power Board forums (0.1.3)

Older Invision Power Board topics didn’t save as one thread. Their pages use &st=30-style offsets, often link to http:// pages from an https:// page, and add a session id to every link, and together those stopped Persistwise from following the pages. 0.1.3 treats the http and https forms of the same site as one site, follows those http page links over https, and it ignores forum session ids when deciding whether two addresses are the same page. Saving one of these threads again also picks up where the archived copy left off, even when the session id or scheme in the link has changed. Search pages and other addresses where those parameters carry real content are left alone.

Readable warnings on light themes

Persistwise follows your Omarchy theme. On some light themes, including Flexoki Light, Catppuccin Latte and Rosé Pine, the theme’s yellow was too faint to read for the Partial thread badge and other warnings. 0.1.2 darkens that colour just enough to be readable while keeping its hue. A few dark themes with a dim warning colour get the same fix, and every other theme looks exactly as before.

Get it

Your existing archive opens as before, and its database is upgraded automatically the first time you start 0.1.1 or later. The v0.1.3 release has an AppImage, a self-hosted Flatpak bundle, a .deb, an .rpm and an Arch package, each with a SHA-256 checksum. On Omarchy, or anywhere you use autonomix-cli:

autonomix-cli add https://github.com/ninepointlabs/persistwise-desktop
